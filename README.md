### 不登入，先看一遍完整操作

按頂端「展示放映」，即可觀看原工作台的登入、逐步建立實單網格、查核啟動、行情跳動，以及兩次部位進出場。放映採 **0.5 倍速，約 2 分 56 秒**，游標會操作原本的視窗與表單；畫面內的大字旁白隨步驟更新，盡量避開正在示範的欄位。

展示全部使用假帳戶、假行情與假成交，無須登入券商，也不會送出真實操作或寫入帳本。點擊展示內的按鈕或嘗試輸入時，會先暫停並詢問「繼續播放」或「停止展示並返回工作台」；該次操作不會執行。繼續會接續原進度，返回會保留原工作台的選取、分頁與輸入，既有監控依原狀態持續。另有暫停、重播及返回按鈕。

展示放映是唯讀導覽；想親手練習，請建立下述「離線展示」策略。

### 設定簡單，常用工作集中

- **基本設定與行情參考：**逐步精靈帶入價格、格數與每筆股數。登入並取得有效成交價後，可用參考價附近區間開始規劃；離線模式不要求先取得行情。最多股數、保留股數、金額與新單筆數等額外限制放在進階選用設定，留空的上限不啟用。
- **草稿、模板與複製：**未完成輸入可自動保存為草稿，從「草稿／模板」續編；常用參數可另存模板。複製策略只帶參數，期初持股與最少保留股數歸零、成本清空，不帶委託、成交或實單授權，儲存後保持暫停。
- **參數匯入／匯出：**「更多功能 → 匯入／匯出策略」可匯出單筆或多筆參數 JSON，讀檔後先預覽、勾選再確認。每檔最多 15 組，同一檔案重複匯入會略過已匯入項目；不攜帶帳戶、庫存、成本、成交或實單授權。參數檔不能代替帳本備份。
- **摘要與網格預覽：**首頁顯示監控、委託、持股與待處理摘要，提供名稱／商品搜尋及圖像化買賣點、規劃金額預覽。歷史委託、成交與事件按策略分頁，隱藏畫面降低查詢頻率，還原時立即刷新。
- **批次啟動結果：**部分策略成功、部分受阻時，獨立結果視窗列出原因與對應入口。已恢復策略持續監控；修正後只重新查核待處理策略，再確認啟動。
- **部位交接與封存：**可把同模式、同帳戶、同商品的既有部位交給另一策略。清單篩選可切到「已封存策略」查看或還原為暫停；模擬策略也可預覽後結束模擬並封存，保留歷史。
- **離線功能說明：**上方「功能說明」開啟滿版手冊，提供主題、搜尋、章節與相關連結；各處「？」直達相應主題，返回保留工作台狀態。

### 桌面入口與結束程式

雙擊 `start.vbs` 檢查環境並開啟桌面工作台。「更多功能 → 版面／字體 → 啟動介面」可改為瀏覽器，下次啟動生效；也可用 `start.vbs --browser` 單次指定。安裝清單包含 PyWebView 6.2.1，桌面引擎另需 Windows 的 WebView2 Evergreen Runtime；缺少時提供官方安裝指引及瀏覽器入口。

關閉桌面視窗會先詢問是否繼續使用或結束程式。選擇結束後依序停止、登出並完成帳本收尾；登出失敗保留視窗，仍有未確認委託時保留結果清單供確認。瀏覽器關閉分頁不會停止後端，請使用工作台的「結束程式」。

本專案為社群開發工具，未受凱基官方背書。本機操作與假資料測試不代表正式券商行情、回報或交易已完成驗收。

## 三步開始

1. [下載最新 Release 的來源包](https://github.com/pypysuper-og/kgi-us-grid-web/releases/latest)，解壓到可寫入的本機資料夾。
2. 雙擊 **`start.vbs`**。缺少環境時自動準備 uv、Python 3.12 x64 與鎖定套件；完整時直接啟動。
3. 桌面工作台開啟後，按「新增網格」選 **離線展示**，預覽、儲存並啟動策略，再用「離線行情」演練。

支援 **Windows 10／11 x64**。首次安裝需要網路，時間依下載速度而定；一般安裝不需管理員權限。uv 不存在時會從 Astral 官方下載固定版本並核對 SHA-256，再建立專案 `.venv`。不取代系統 Python，也不修改永久 PATH。

日常啟動推薦 `start.vbs`：不保留 CMD／PowerShell 視窗。若只想先安裝環境，可雙擊 `install.vbs`；`.cmd` 入口也可用，但可能短暫閃過外殼。安裝檢查不會登入券商或送出委託。

啟動視窗會在檢查既有工作台之前顯示，持續顯示階段、經過時間及即時遮蔽安裝訊息；環境準備完成後，保留到帳本與市場日曆載入、桌面視窗就緒或所選瀏覽器開啟。已有相容的 Python 3.12 環境會沿用；缺少安裝收據時先核對鎖定套件，無須另下載 Python。準備階段可取消；後端啟動後可「隱藏提示」，不會停止背景程式。套件同步最多等待15分鐘，匯入驗證另有2分鐘上限；後端就緒最多等待180秒。失敗會顯示原因，瀏覽器開啟失敗時提供本機網址；就緒等待逾時不強制停止或重啟後端。

**更新版本：**先在工作台備份帳本並正常結束程式，待桌面視窗完成收尾關閉，或瀏覽器顯示「程式已結束」後，再從新版資料夾執行 `start.vbs`。帳本使用下述本機資料位置，登入原帳戶後依恢復流程查核並啟動。已開啟的後端不會因下載新版或重開介面而替換；版本可在畫面底部確認。

## 從練習到正式交易

| 模式 | 行情來源 | 委託處理 | 是否需要正式登入 |
| --- | --- | --- | --- |
| 離線展示 | 你輸入的價格 | 本機撮合 | 否 |
| 行情模擬 | KGI 正式行情 | 本機撮合 | 是 |
| 正式交易 | KGI 正式行情 | KGI 複委託實單 | 是，且須另外啟用實單 |

「行情模擬」是本程式的撮合模式，並非券商提供的美股模擬交易環境。每次程式重新啟動，實單預設停用。

正式使用流程：**登入 → 明確選帳 → 確認實單（額外額度可選填） → 查核委託與部位 → 啟動策略**。登入過程的 SDK 輸出會在介面動態展示；主畫面分開顯示本機連線、券商連線及所選帳戶。

實單設定由此帳戶的正式策略共用。「全部啟動監控」會列出本次策略數量與名稱，確認帳戶限制後返回整批對帳。成功確認後保存此帳戶的每日買入上限、新實單筆數及成交回報時區，重新開頁面或重啟程式會自動帶入；其他帳戶分開保存。每次啟用仍須勾選確認，儲存參數不會自動恢復實單授權或啟動策略。送單筆數是本程式此帳戶共用的剩餘額度，每次重新啟用會依填入筆數重新設定，並非各策略各自取得一份。

按下登入後，帳密、正式登入確認框及送出按鈕暫時鎖定，SDK 輸出持續更新。失敗後恢復輸入；成功後切換到選帳頁，選帳完成關閉登入小視窗。

開始前須自行完成凱基 API 開通、複委託資格、CA 憑證及官方憑證元件設定，參照[凱基官方前置設定](https://superpy.kgieworld.com.tw/kgipythonapi/guide/tw/prefix)。本儲存庫不附憑證、帳號資料、SDK 原生安裝程式或券商錯誤碼檔。需要 `errMsg.ini` 時，請使用券商提供的版本；未提供仍可呈現回傳的原始錯誤碼與原因。

## 網格怎麼運作？

有有效行情時可先以成交價附近的區間開始；離線時直接填寫即可。填上下界與價格間隔數，精靈計算價差及預設中點；也能修改價差或起始價，參數會動態連動。不能精確到目前支援的 0.01 美元時，畫面提供可用格數建議，不暗中四捨五入。

例如下界 **4.00**、上界 **5.00**、**50 個間隔**：價差 **0.02**、預設起始價 **4.50**，得到 **51 個參考價位**。這是格線預覽，並非一次送出 50 筆委託；實際候選受方向、部位與資金限制，每策略同時最多一筆未結束網格單。

目前支援多頭現股、整數股、正常盤及至少 1 美元的商品。最新成交展示使用 `USQuote` 訂閱，交易觸發使用 `USData` 快照；等待首筆、行情過期與斷線各自標示。行情過期只等待更新，無須重新啟動策略。

## 斷線、拒單與停止，都有下一步

- **斷線恢復：**依 1、2、4…秒退避，最高 300 秒、不限次數。原帳戶重連後自動補查成交與庫存，恢復可核對的原監控與所需行情；有未能對應的差異才請使用者處理。手動停止的策略保持停止，送單額度不重置。
- **查核重試：**暫時無法核對的策略以 60、120、240 秒，之後每 300 秒重新查核。庫存與委託確認一致才恢復原監控，沿用原會話的剩餘額度；其他已確認策略照常運作。已確認拒單、撤單、到期或策略超過停止日期需由使用者處理，背景查核不建立替代委託。
- **人工接手：**開啟該策略的對帳、查單、編輯、停止或啟動流程，即停止其背景查核與自動恢復。關閉視窗不重新取得自動恢復意圖；後續依人工對帳及啟動流程處理。即使券商查詢尚未完成，已收到的接手命令也會阻止自動啟動。
- **回報未明：**保留原委託並查核，不因等不到回報而重送。確定拒單可查看錯誤碼／券商原因，符合條件時由使用者確認重新送單。
- **停止監控：**逐次選擇保留委託或嘗試撤單；停止新單不等於平倉，也不等於券商已確認撤單。
- **結束程式：**先登出，再結束後端。若仍未取得撤單確認，結束畫面列出需在券商 App 手動查核的委託。關閉瀏覽器頁面不會停止策略，請使用工作台的「結束程式」。

## 帳本、成本與你的資料

**編輯策略：**先停止並處理在途單，再按「編輯」。預設保留目前網格基準、部位及成交；改間距則以原基準推算下一格。例如起始6.00、間距0.03，買在5.97後提高預算，下一買點仍是5.94。需要重新定位網格時，明確勾選「重設基準為本次起始價」；預覽會使用選定基準與目前持股，儲存不自動啟動。

**價格界線：**預設限制委託限價，允許價格改善後成交在下界以下。例如下界5.50、買單限價5.53，仍可能成交於5.30。勾選「行情低於下界時不新增買單」後，低於下界只等待，回到範圍自動繼續；已送委託不自動撤銷，也不保證成交價落在界線內。

**逐筆查核：**在「委託」頁按「送單依據」，查看送單時行情、基準、持股及預算檢查。按「查詢券商委託」可讀取當下報表，顯示未配對、參數衝突及人工配對來源；保存查核可回看最近20次，較早紀錄仍留在本地帳本。查詢不自動認領或重送。舊版未留存的決策、成交日期／時區或費用，不會使用目前資料補猜。

資料保存在本機 `%LOCALAPPDATA%\KGI_US_Grid_Trading_Web\runtime`，與程式資料夾分開。SQLite 使用 WAL；運作中請透過「備份帳本」取得一致備份，不能只複製主資料庫或刪除 WAL／SHM。既有帳本可能依版本升級，不宜直接用舊版程式開啟新版資料庫。

`restore.py` 可將本程式支援的第 1 至 5 版帳本備份還原到尚不存在的新 runtime 目錄，保留成本與已記憶的設定；下一次啟動仍保持暫停、實單停用，須重新登入與對帳。未知或較新 schema 會先拒絕，不覆寫現有目錄。本版帳本格式為第 5 版，保存部位交接、模擬退場與快照；更新前先備份並正常結束，請勿用舊程式開啟新版帳本。

成本採 **USD 移動加權平均**；未知期初成本不當成零。結算方式可選 TWD／MUT，歷史委託保留當時設定，不推估匯率或台幣損益。成交來源日期／時區不完整時標示資料品質，量價已核對的成交仍可入帳；不能確定的單日損益保留未知。

本機預算與持股檢查不等於券商可用資金或可賣量保證；其他平台的委託仍需一併核對。稽核範圍涵蓋業務操作與交易流程，不逐筆保存所有市場 tick，也不承諾完整重播行情。

每次重連及背景查核都追加比對證據至 SQLite 帳本與應用程式 audit：策略設定及版本、遮蔽帳戶參照、會話與額度、查詢及接收時間、券商庫存欄位、本地各策略分配、已確認額外持股、預期數量及差額、使用的委託／成交報表、錯誤與處置結果。查詢失敗會記為未知，與成功查詢到零股分開；人工接手也會記錄。這些證據支援事後排查，歷史缺漏的資料不會補造。

## 遇到安裝或啟動問題？

| 狀況 | 處理方式 |
| --- | --- |
| 首次下載失敗 | 確認網路／防火牆後重開 `start.vbs`，不需先刪除環境 |
| 套件異常 | 工作台正常結束後執行 `wscript.exe install.vbs -Repair` |
| 同一工作台已啟動 | 再次執行 `start.vbs`，會開啟既有工作台頁面 |
| 8765 被其他程式使用 | 執行 `wscript.exe start.vbs --port 8766` |
| 想用獨立測試帳本 | 執行 `wscript.exe start.vbs --runtime "D:\GridTest\runtime" --port 8766` |
| Windows Script Host 被管理政策停用 | 由 IT 允許此入口，或從 PowerShell 執行下方命令 |

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -NoUI
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\start.ps1
```

安裝與啟動階段的紀錄在 runtime 上層 `logs\bootstrap.jsonl`；交易稽核在 `runtime\logs`，可從 Web 下載本次遮蔽紀錄。套件安裝成功不等於正式登入已驗證，登入資格／憑證問題請依 Web 的 SDK 輸出判讀。

## 開發與驗證

使用 Python 3.12、FastAPI、SQLite 與 uv，無須前端編譯。這個公開儲存庫提供可執行的乾淨來源與安裝入口，未包含正式帳本、日誌、憑證或私有 SDK 元件。

已在 Windows 隔離目錄驗證：沒有 Python／uv PATH 的首次安裝、隱藏啟動、完整環境跳過安裝、使用中環境阻止重裝、離線成交、Edge 顯示、正常結束與重啟後持股保留。正式券商交易及其他 Windows 電腦的官方憑證元件，不屬於上述測試證據。

## 過期策略的部位交給新策略

策略過期不會解除部位歸屬。有部位時仍不能直接封存；把同一批持股再登記給新策略，會造成合計分配超過券商持股。

1. 先備份帳本，停止同帳戶同商品的策略監控，處理所有在途／未知委託。
2. 從舊策略列按「交接部位」，選擇同模式、同帳戶、同商品的策略。正式策略也可由庫存分配阻擋結果的「交接既有部位」進入；模擬部位的本機交接不要求登入券商。
3. 若新策略已重複登記相同股數，且還沒有任何委託、成交或先前交接，確認是同一批持股後才勾選更正重複期初登記。其他情況先停止處理，不會自動合併已有交易的策略。
4. 按查核，核對前後股數、成本與券商持股，勾選確認後交接。例：舊10股、新10股重複登記，更正並交接後為舊0股、新10股，承接舊成本。
5. 完成後兩邊仍暫停，舊策略可封存；新策略重新對帳，再由使用者確認啟動。

這只變更本機歸屬，不下單、不撤單、不移轉券商資產。舊策略的成交與已實現損益不搬家，成本未知仍保持未知。新策略成本損益頁可追查承接來源；原策略的成本／費用後補證據仍會反映到剩餘部位。回覆中斷時可先「查詢本次交接結果」，不自動重送。

最多股數、最低保留與金額限制集中在進階設定／選用風控。持股上限與金額限制留空不啟用；最低保留0股表示不保留。每筆股數、價格上下界、結算與停止日期仍是基本策略設定。
